# ABI evidence transport (R7j1)

Measured ABI facts are not timeless truths. They are evidence produced for a specific native boundary, target, toolchain, and ABI relevant input identity. Semantic artifacts may transport native ABI evidence, but consumers must validate its identity before using it.

`concept-module.v1` has an optional, hash covered `native_abi` report. It is the same `NativeABIReport` written to `.native-build/abi.json`. Each measured type records its companion source digest, declaration name, field names and offsets, size, alignment, `NativeToolchainProbe` origin, and structured identity. The report contains the compiler family and version, target triple, host OS and architecture, native build input hash, and semantic companion hash. Probe source is diagnostic input, never semantic authority.

The build input hash deliberately covers the whole native build plan: manifest claims, compiler version, source and header bytes, include roots, defines, language standard, command arguments, and link inputs. This is conservative. A change that does not alter ABI can cause a reprobe, while the opposite mistake would permit a stale proof. Native output hashes remain in `build.json`; `concept build/test` validates those hashes before using the outputs. Binding an external artifact only consumer to a separately supplied archive is still open.

`CompileNativeSemanticModule` checks that the source is a declared companion, obtains the measured report, compares every local `repr(C)` declaration with its measured geometry, and embeds the report. `BuildNativeCompanionArtifacts` orders declared companion modules by semantic imports. A consuming module supplies `NativeABIIdentity` to `ParseWithSemanticModulesForNative` or `CompileSemanticModuleWithNativeABI`. The import loader checks identity before sema. Matching evidence is reused. A changed identity requires reprobe; if the boundary cannot be reconstructed, the import is rejected. `EnsureNativeABIReport` reuses a matching `abi.json` or reruns the native compiler probe. It never treats a missing or incomplete report as a proof.

An old v1 artifact without `native_abi` still imports declarations. An imported by value foreign aggregate call requires validated evidence. `CAbiLayout` for an imported aggregate without evidence is Unknown. With matching evidence, Concept rechecks field eligibility and derives `CAbiValue` with a `NativeToolchainProbe` proof node containing geometry and identity. `DeclaredForeign` operation contracts retain their own origin.

The artifact dependency hash binds B to A. In an A→B→C chain, C loads A transitively and validates A's measurement; B does not copy a naked Proven bit. Native linking still requires an external library. No runtime ABI registry, runtime identity check, C++ parser, or register classification is introduced.
