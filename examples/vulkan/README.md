# Vulkan examples

`profile Vulkan;` is Core plus Vulkan setup that would otherwise be written by
hand: the `Vulkan` library is imported implicitly, and `concept test` links the
Vulkan runtime (the GPU-free test device by default,
`CONCEPT_VULKAN_RUNTIME=device` for a real loader).

```text
go run ./cmd/concept check examples/vulkan/BufferLifetime.concept
go run ./cmd/concept test examples/vulkan --verify
```

`DoubleKernel.concept` and `ScaleKernel.concept` are generated by
`concept vulkan-bind` from `kernels/*.spv`; regenerate them when a kernel's
interface changes (`concept test` reports stale ones):

```text
glslc --target-env=vulkan1.3 examples\vulkan\kernels\scale.comp -o examples\vulkan\kernels\scale.spv
go run ./cmd/concept vulkan-bind examples\vulkan\kernels\scale.spv -o examples\vulkan\ScaleKernel.concept
```

`kernels/scale.hlsl` is the same kernel for `dxc -spirv`.

On a machine with a GPU and the Vulkan SDK, `tools/vulkan/run_gpu.ps1` runs the
whole device check, including the C reference in `reference/compute_dispatch.c`
and a synchronization-validation pass, and logs to `tools/vulkan/out/gpu.log`.
